Drum Annotator — PoC 2 手動アノテーション

やり方
  1. Space で区間を再生して聴く (50% のスロー・ループ再生)
  2. キックが鳴った所を 赤い段、スネアは 青い段、ハイハットは 緑の段 でクリック (印は音の立ち上がりの始まりに自動で合う)
  3. 間違えたら、その印をもう一度クリックで消す (⌘Z で元に戻す)
  4. 区間 1〜3 を順にやって (→ で次の区間)、最後に「保存」
シンバル (ライド・クラッシュ) とタムには印を付けない。聞き取れない音は付けなくてよい。
原曲 (または PoC 1 の drums.wav) と annotation.yaml を選んでください。音源はブラウザの外に送られません。
速度
K キック (低域レーン) S スネア (中域レーン) / Shift+クリックでゴースト sg H ハイハット (高域レーン)
レーンをクリック = その楽器の打撃を追加 / 既存の印をクリック = 削除 / 一番上の波形をクリック = そこから再生 / ←→ 区間の切り替え
