# Play-along with a Beat Click (2026-10-04)

`poc record --click` で、原曲の拍に合わせたクリックを伴奏に重ねて録音できるようにした。
あわせて、開発者の演奏そのものを原曲の Reference と比べた。これはアドホックな分析で、Performance Analysis の機能はまだ実装していない (PoC 3 の Bar / Beat マッピングの後に実装する)。

## クリックの仕組み

- 拍の検出は Beat This! (`beat-this` 1.1.0, checkpoint `final0`, CPU)。`docs/poc-plan.md` で PoC 3 用に採用済みの技術を前倒しで導入した。
- 入力は PoC 1 run の `drums.wav + accompaniment.wav`。再生する伴奏とタイムラインが一致する。結果は `output/runs/<run_id>/beats.json` にキャッシュする (初回は重みのダウンロード込みで約 100 秒、以降は数秒)。
- 小節頭 (downbeat) は 1600 Hz、その他の拍は 1000 Hz。直前の拍との間隔が拍間隔の中央値の 0.6 倍未満の拍は鳴らさない (検出の乱れで二重に鳴るのを防ぐ)。
- クリックは伴奏と同じく再生側にだけ入る。録音したドラム音への回り込みは見られなかった (ADTOF の Precision 0.94〜1.00、伴奏に残った元のドラムからの検出 0)。
- `recording.json` の `click` にクリックの設定 (クリック数・音量) を記録する。

### 拍の検出結果

| 曲 | BPM (拍間隔の中央値) | 拍 | 乱れた箇所 |
|---|---|---|---|
| NO. NEW YORK | 166.7 | 677 | 1:48〜2:00 (ドラムのない区間)、3:58 以降のエンディングはハーフテンポ |
| B・BLUE | 166.7 | 654 | 3:09 付近の 1 小節で拍が細かく割れる |

原曲の Kick / Snare (ADTOF) は検出した拍より 3〜13 ms 早い位置にあり、拍の位置はおおむね原曲のドラムと一致している。

## 演奏の比較方法

- Reference: 原曲の drum stem を ADTOF で採譜したイベント (B・BLUE `20261004-012826_e14bdec6`、NO. NEW YORK `20261004-012813_7c2129d2`)。市販音源の手動アノテーションはまだないため、Reference 自体に誤りが含まれうる。
- 演奏: TD-17 の MIDI から作った `groundtruth.json` (連続トリガー除去・キャリブレーション済み)。Snare のゴーストノートは EXTRA に数えない。
- 楽器ごとに ±50 ms で 1 対 1 対応付け (`poc.evaluation.matching._assign`)。ズレは「演奏 − Reference」(+ が遅い)。ADTOF の一定の偏り (kick −7.4 / snare −3.0 / hihat −2.2 ms, R-17) は補正した。
- Tom / Cymbal は対象外。

## 結果

### B・BLUE

| | HIT 率 (クリックなし → あり) | ズレ中央値 ms | ばらつき (std) ms |
|---|---|---|---|
| Kick | 54% → 52% | +7 → −13 | 26 → 25 |
| Snare | 73% → 77% | +9 → −7 | 23 → 23 |
| HiHat | 75% → 77% | +11 → −11 | 23 → 23 |

録音: クリックなし `20261004-044116_3e21c73e`、クリックあり `20261004-050945_3e21c73e`。

- クリックありでは、クリックより約 13 ms 前で叩く傾向に変わった。
- クリックなしで +19〜26 ms 遅れていた 2:30〜2:45 は、クリックありで Snare 15/23 → 23/23 に改善。代わりに 2:00〜2:15 と 2:45〜3:45 で Kick が −25〜−35 ms 早くなった。
- イントロ (0:00〜0:15) の Kick と 3:15 以降の HiHat (原曲は Cymbal と判定) はアレンジの違いで、どちらのテイクでも一致しない。

### NO. NEW YORK

| | HIT 率 (クリックなし → あり) | ズレ中央値 ms | ばらつき (std) ms |
|---|---|---|---|
| Kick | 52% → 67% | +9 → 0 | 25 → 28 |
| Snare | 65% → 73% | +12 → +6 | 25 → 25 |
| HiHat | 50% → 63% | +9 → +2 | 26 → 24 |

録音: クリックなし `20261004-043201_6846e9b3`、クリックあり `20261004-051700_6846e9b3`。

- 2:15〜3:00 は両方のテイクで崩れる。原曲は 2:30 で Floor Tom から HiHat に戻るが、演奏は 2:45〜2:50 まで Floor Tom (note 43) を続けている。クリックありのテイクでは、この区間で原曲より −57 → −70 → −100 ms と早くなり、3:00 でグリッドに戻る (3:00〜3:15 は Kick / Snare とも 21/21)。
- 0:30〜1:00 の Snare は +22〜32 ms 遅い (Kick / HiHat は遅れが小さい)。

## 考察

- クリックで全体のズレの位置 (中央値) は変わるが、1 打ごとのばらつき (std 23〜28 ms) はどちらの曲でも変わらない。
- 苦手区間は 15 秒刻みでも見つけられた。小節単位で示すには PoC 3 の Bar / Beat マッピングが必要。
- Reference の Kick は原曲の drum stem の ADTOF 推定で、市販音源での精度は未確認。Kick の MISS が多いのは、演奏の問題か Reference の誤検出か切り分けられていない。
