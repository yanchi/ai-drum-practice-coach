# PoC 2 Evaluation: Drum Event Extraction

- **Date**: 2026-10-04
- **Spec**: [specs/002-drum-event-extraction/spec.md](../../specs/002-drum-event-extraction/spec.md)
- **Status**: **条件付き Go** (2026-10-04 Human Review で承認)。手動アノテーション (T044) で SC-003 / SC-009 を確かめてから Go を確定する。

## 結論

**条件付き Go** — PoC 3 (Beat / Downbeat 解析と Bar / Beat へのマッピング) に進む。ただし、手動アノテーション (T044) で市販曲の精度 (SC-009) を確かめてから Go を確定する。

HiHat の検出閾値は 0.22 → 0.12 に変更した (下記「閾値の調整」)。以下の数値は、特に断りがなければ変更後の閾値によるもの。

電子ドラム (Roland TD-17) の演奏を正解にした評価では、Kick / Snare / HiHat とも F1 が 0.80 を上回り、タイミング誤差も目標内に収まった。処理は 4 分の曲で約 10 秒と速い。
一方で、ゴーストノートはほぼ検出できず、推定した強さと velocity の相関も弱い。また正解はすべて電子ドラムの音色で、市販曲の生ドラムでの精度はまだ測れていない。

## Drum Stem と Mix (分離なし) の比較

| 楽器 | F1 drum stem | F1 mix | 差 |
|---|---|---|---|
| kick | 0.923 | 0.892 | −0.031 |
| snare | 0.930 | 0.852 | −0.078 |
| hihat | 0.867 | 0.869 | +0.002 |

Kick / Snare は分離した方が良く、特に Snare で差が大きい。HiHat は閾値を 0.12 にすると差がなくなる (既定の閾値では stem 0.846 / mix 0.807)。Demucs による分離 (PoC 1) を前段に置く構成を維持する。
伴奏 (accompaniment) に残った元のドラムからの検出は、閾値の変更後も 5 曲とも全楽器で 0 だった。

## 閾値の調整

`poc tune-thresholds` で、閾値を 0.06〜0.30 で探索した (5 曲の leave-one-out)。

| 楽器 | ADTOF の既定 | 全曲で最良 | F1 既定 → leave-one-out | 決定 |
|---|---|---|---|---|
| kick | 0.22 | 0.16 | 0.923 → 0.922 | 0.22 のまま (改善なし) |
| snare | 0.24 | 0.16 | 0.930 → 0.932 | 0.24 のまま (改善は誤差の範囲) |
| hihat | 0.22 | 0.12 | 0.846 → 0.861 | **0.12 に変更** (FP が増えても F1 が上がる) |

2026-10-04 の Human Review で HiHat を 0.12 にすることを承認し、`poc/transcription/adtof_adapter.py` の `TUNED_THRESHOLDS` に反映した。手動アノテーション (生ドラム) で同じ傾向になるかも確かめる。

## そのほかの観察

- **ゴーストノート**: Snare のゴーストノート (velocity < 40) は 922 打中 7 打しか検出できない (約 1%)。原因は未確認。現状では、ゴーストノートを Reference との比較に使えない。
- **強さと velocity の相関** (Spearman, 曲ごと): kick 0.34〜0.54、snare −0.00〜0.22、hihat 0.42〜0.62。Snare はほぼ無相関で、推定した強さをダイナミクスの評価にそのまま使うことはできない。
- **時刻合わせ**: パッドごとのずれ −2.2〜−4.0 ms をキャリブレーションで補正した。TD-17 が 1 打に対して送る余分なノート (キックの跳ね返り、スネアの連続トリガー) を 1 曲あたり 500〜790 個除いた。
- **練習用のクリック**: Beat This! で原曲の拍を検出し、録音時のクリックに使った (research R-18)。クリックは録音したドラム音に回り込まない。詳細と、開発者の演奏を原曲と比べた結果は [play-along-click.md](play-along-click.md)。

## 評価の限界

- **音色**: 正解はすべて電子ドラム (TD-17) の音。市販曲の生ドラムの音色・響き・ミックスでの精度は、手動アノテーション (SC-009) で確かめるまで分からない。
- **ジャンル**: 評価セットは全曲ロック (167 / 187 BPM)。ほかのジャンル・テンポは対象外。
- **演奏者**: 正解は開発者 1 人の演奏で、ハイハットの強さなどの癖が結果に影響する (ONLY YOU の HiHat)。
- **閾値**: HiHat の閾値は同じ 5 曲で選んだ。leave-one-out の F1 (0.861) が、未知の曲での見込みに近い。
- **手動アノテーション**: まだ 0 曲。仮データでの動作確認のみ行い、結果は集計から外した。
- **PLASTIC BOMB**: PoC 1 の評価セット外で、分離の再現性 (`check-repro`) は未確認。
